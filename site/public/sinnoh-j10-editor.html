J10 — Desenhar os cinco mapas originais

Ferramenta de autoria local no navegador. O tileset PNG não sai do seu dispositivo: nenhum upload, armazenamento remoto ou comunicação com GitHub. Mapas desenhados não são mapas instalados nem aprovam R07 (IDs), R08 (direitos) ou R09 (43 Windows + 1 Android).

1. Cena e tamanho

Redimensionar conserva tiles na área sobreposta. Confirme a geometria antes de exportar; não são inferidas coordenadas, passabilidade nem eventos.

2. Tileset autorizado
Nenhum PNG selecionado.

O arquivo original do PNG deve ser copiado separadamente para .blue-work/sinnoh-j10-tilesets/, com o mesmo nome e hash do JSON.

3. Camadas
Selecione um tile no quadro do tileset.
4. Autoria e exportação privada

Exporte cada um dos cinco mapas separadamente. Não há exportação de RXDATA no navegador: use o validador Python J10 local após fornecer os cinco arquivos e o(s) PNG(s) autorizados.

Palette do tileset

IDs RMXP: primeiro tile 384. Use a barra de rolagem para escolher outras linhas; não há suporte automático a autotiles 48–383.

Desenho em três camadas

Depois de desenhar os cinco mapas: coloque os arquivos JSON em .blue-work/sinnoh-j10-drafts/ e cada PNG autorizado em .blue-work/sinnoh-j10-tilesets/, sem renomeá-los. Execute python scripts/regions/author_sinnoh_playable_j10.py (auditoria sem escrita) e, após corrigir todos os bloqueios, python scripts/regions/author_sinnoh_playable_j10.py --build. Os cinco RXDATA serão criados somente no diretório privado da J09. Consulte a documentação da J10 antes de enviar qualquer arquivo.
